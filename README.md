Web Development Fundamentals – Practice Repository

This repository contains my early practice files created while learning the fundamentals of HTML, CSS, and JavaScript.

These files represent the starting point of my frontend journey — where I learned how the browser works, how HTML structures content, how CSS styles elements, and how JavaScript brings interactivity to life.

The goal of this repository is learning, experimentation, and concept clarity, not polished production code.

---

📘 What This Repository Contains

The files in this repository focus on core building blocks of the web:

* HTML structure and tags
* Inline and internal CSS
* Buttons and user interaction
* JavaScript basics
* Browser alerts and console output

These were written before moving on to larger projects like calculators, carts, and games.
